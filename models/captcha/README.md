# Модель капчи HH

В этой папке лежат файлы для локального распознавания капчи:

- `model.pt` — веса CRNN+CTC;
- `charset.txt` — алфавит, использованный при обучении этих весов.

Файлы в корне `models/captcha/` — основная модель (`default`). Через
«Настройки → Капча HH» можно загрузить дополнительные версии: они хранятся
в `models/captcha/<имя>/` и содержат собственные `model.pt` и `charset.txt`.
Если при загрузке алфавит не указан, используется текущий основной алфавит.
После загрузки выберите версию в списке и нажмите «Выбрать модель»; перезапуск
для переключения не нужен.

Git и Docker build исключают файлы моделей. Docker Compose подключает папку
для чтения и записи, чтобы загрузка через веб-интерфейс сохранялась на хосте.

Текущие файлы взяты из `/home/user/captchas/model/final_all.pt` и
`/home/user/captchas/model/charset.txt`.
